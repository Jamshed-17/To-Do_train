Эта программа - супер простой to-do лист, в котором можно добавлять элемент, удалять элемент и выводить все элементы. 

API:

get: `[host]/api/get` - получение всех задач на данный момент в виде:
```json
[
  {
    "id": 2,
    "name": "gg"
  },
  {
    "id": 3,
    "name": "ne"
  },
  {
    "id": 4,
    "name": "qwertyuiop[]"
  }
]
```
post:`[host]/api/create` - Создаёт новую задачу. Отправляется json в виде:
```json
{
  "id": 0,
  "name": "string"
}
```
id указывай любой, у нас просто один дебил этим занимался, остался этот баг. 

post:`[host]/api/remove/{id}` - Удаляет запись по id
